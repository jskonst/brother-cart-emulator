# Картридж узоров CK-35

Проект про картридж Brother CK-35: страница по Wi-Fi, на которой рисуют узор, и плата, которая отдаёт его машине как память картриджа. Байтовый формат узора ещё не подтверждён дампом. Пока его нет, прошивка образ картриджа не собирает.

CK-35 своих узоров в памяти машины не хранит. Узор приходит с картриджа, картридж заполняет PPD-35, и машина умеет записать свою память обратно в картридж. Вставка картриджа очищает память машины. Это описание из [заметки ETI Berlin](https://etiberlin.wordpress.com/2013/12/16/the-ck-35-what-i-have-learned-so-far/) и руководств Cartridge Utility, не из нашего дампа. Поэтому оригинальный картридж сначала читают отдельным дампером и только потом снова ставят в машину или в PPD. Батарею на плате измеряют до этого: севшие элементы на таких картах обычны, и тогда ОЗУ уже пустое.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `knitting-cart/` | Чертежи Грегора Рипла, Stitch Pattern Cartridge II и эмулятор на ATmega165PA. Лицензия CERN OHL 1.2, не MIT. Атрибуция в `knitting-cart/NOTICE.md`. Прошивки там нет |
| `firmware/ck35-editor/` | ESP32, точка доступа и страница с сеткой. JSON в LittleFS. Шину картриджа не трогает |
| `hardware/dumper/` | Читатель на Arduino Mega 2560. Только чтение: контакт записи удержан железом, контакт батареи на 5 В не сажается |
| `docs/` | Разбор, что известно про CK-35, и план |
| `legacy/` | Старый программатор вышивальной карты. В CK-35 не вставлять |

Сборка редактора: `pio run` в `firmware/ck35-editor/`. Сборка дампера: `arduino-cli compile --fqbn arduino:avr:mega hardware/dumper/mega/ck35_dump`.

Редактор поднимает сеть `CK35-Editor`, пароль `ck35-editor`, адрес `http://192.168.4.1/`. Домашний Wi-Fi подхватывается только если в LittleFS лежит `/sta.txt` из двух строк. Пароль точки доступа напечатан в UART и его стоит сменить в `pattern_editor.cpp`.
