# legacy: программатор вышивальной карты

Сюда перенесено то, что было в корне форка AeroX2/brother-cart-emulator:

- `code-esp32/` — прошивка ESP32, которая стирает и пишет SST39SF040;
- `pcb-esp32/` — плата края вышивальной карты, шаг 1.00 мм, одна сторона, 76 × 50 мм;
- `image-dumper/` — скрипт Windows вокруг PED-Basic, не читатель вязального картриджа.

Эту плату и эту прошивку нельзя вставлять в CK-35 и нельзя подключать проводами к оригинальному картриджу. `FlashChip::init()` делает WE выходом, команда `W` стирает чип, GPIO ESP32 сидят на шине 5 В.

Редактор узоров для CK-35 лежит отдельно: `firmware/ck35-editor/`. Он шину картриджа не трогает.

Разбор старой платы остаётся в `docs/ANALYSIS.md`, в разделе про вышивальную карту.
